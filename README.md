# 🌸 Rose Garden 20/10 — Chúc Mừng Ngày Phụ Nữ Việt Nam

Trang web thiệp chúc mừng tương tác nhân ngày Phụ nữ Việt Nam 20/10 với hoạt ảnh đóa hoa nở rộ, hiệu ứng cánh hoa rơi 60fps mượt mà, âm thanh hộp nhạc dịu êm và bức thư chúc mừng chân thành từ trái tim.

![Preview](src/assets/pastel-rose-garden.webp)

## ✨ Tính năng nổi bật

- 🌹 **Đóa hồng nở rộ tương tác**: Hoạt ảnh SVG đóa hồng chuyển động mượt mà khi chạm vào để bước vào khu vườn hoa.
- 💌 **Bức thư 20/10 chân thành**: Bức thư ý nghĩa được định dạng phong thư thanh lịch, trang trọng dành tặng những người phụ nữ tuyệt vời.
- 📋 **Sao chép bức thư 1-click**: Hỗ trợ sao chép nhanh toàn bộ nội dung thư để gửi qua Zalo, Messenger, SMS.
- 🌸 **Cánh hoa & Bụi sao 60 FPS**: Hiệu ứng cánh hoa rơi nhẹ nhàng trên Canvas HTML5 và hiệu ứng bung nở sao lấp lánh khi chạm vào màn hình.
- ♫ **Nhạc nền hộp thư du dương**: Tích hợp âm thanh hộp nhạc bằng Web Audio API (0 MB file tải về, chạy mượt mà không độ trễ).
- 📱 **Tương thích hoàn hảo (Fully Responsive)**: Tối ưu hiển thị đẹp mắt trên cả điện thoại (iOS, Android), máy tính bảng và màn hình máy tính.

## 🛠️ Công nghệ sử dụng

- **React 19**
- **Vite 7**
- **Framer Motion**
- **HTML5 Canvas API** (Hiệu ứng hạt & cánh hoa)
- **Web Audio API** (Tổng hợp âm thanh nhẹ tênh)

## 🚀 Hướng dẫn cài đặt & chạy

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (Dev)
npm run dev

# Đóng gói sản phẩm (Build)
npm run build
```
